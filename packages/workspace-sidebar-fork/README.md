# Experimental workspace sidebar source candidate — not installable

This is an initial R7 source integration candidate, **not a completed fork, package, deployment, or E2E pass**. Do not install it in a DSH profile. `upstream/src` is the complete 28-file `ui-workspace/src` tree from public commit `b830ec950faba0a46dda564be3e2d854afed94f1`; `upstream/manifest.json` pins Git blob identities and lengths and `upstream/LICENSE` retains the upstream MIT notice. `candidate-src` is a copy with the experimental changes; compare the directories for the exact source delta. The public source commit and the locally installed rc.5 asset are **not yet proved equivalent**.

The candidate wraps each *already selected* native root in `LineageGraft`, adds an optional toggle inside the existing `SessionNodeItem`, and uses the shared `session-tree/lineage.mjs` projection. It wires explicit expansion to `sessions.refreshProjections` and opens visible child rows with the direct-parent address. Grouped and flat views are patched; the search renderer, original tree derivation, native watermarks and root keys are unchanged. Expansion does not request children until the user opens a root; closing a root discards descendant expansion state. This is a narrow synthetic prototype, not evidence that upstream native behavior or host authorization is preserved.

## Blocking gaps

- The upstream pnpm workspace manifest, lockfile and selected compiler/build manifests are preserved in `upstream/build-metadata` and checked against exact Git blob IDs. The actual workspace sources and dependency/build closure are absent; the candidate has **not been type-checked or built** with upstream's pinned TypeScript/tsdown toolchain. The lockfile pins pnpm 11.28.5, TypeScript 6.0.3, tsdown 0.22.2, lightningcss 1.33.0 and Vitest 4.1.11. Following all workspace links, including dev and optional dependencies, visits 296 importers; this is a graph upper bound, not a minimal build closure. The available local pnpm is 11.25.0 and TypeScript is 7.0.2; no exact installed tsdown/lightningcss toolchain was found. The adjacent `lineage.mjs` must be included by the eventual package build, with a verified dependency contract.
- Local TypeScript 7.0.2 `--noCheck --noResolve` transpiled only the graft for the synthetic browser experiment. A separate strict TS7 diagnostic with intentionally narrow test stubs found and fixed unchecked array access, then passed; these stubs and compiler are not the real upstream types or pinned TS6 and cannot prove the candidate builds. Run `TSC_ENTRY=<reviewed-tsc-entry> R7_TYPECHECK_BASE=<existing-writable-directory> node packages/workspace-sidebar-fork/test/typecheck-graft.cjs`; the diagnostic retains its isolated fixture directory.
- Root lists supplied to the shared projection are scoped to each native group; cross-workspace identity, host-enforced authorization, incomplete catalogs, stale refresh and ownership boundaries require a design and real tests before enablement. Never treat a string, projection, or this code as an authorization proof.
- Native accessibility/tree semantics, keyboard focus and recovery, touch and drag behavior, statuses/avatars, localized errors, screen readers, subscription lifecycle, multiple simultaneous requests and animated row interactions need full integration work. Child `role=treeitem` elements are currently siblings under a separate group rather than nested inside the native parent treeitem. The candidate is not accessible-feature complete.
- Search remains native and does not search lineage children; catalog loading and per-level errors are rudimentary. Real Host transport, persistence, concurrency, package installation, rollback and visual behavior are all unverified.

## Current tests

`node --test packages/workspace-sidebar-fork/test/*.integration.mjs` checks the shared projection adapter and verifies the pinned source blobs, plus static equality of native search, list derivation and watermark functions. These assertions do not prove native behavior.

`LOCK_YAML_MODULE=<reviewed-js-yaml-module> node packages/workspace-sidebar-fork/test/lock-closure.cjs` inventories reachable `link:` importers in the exact pinned lockfile. This read-only count includes dev/optional links and does not install packages or resolve external artifacts.

`test/graft-browser.integration.cjs` is opt-in: it uses the same `PLAYWRIGHT_PATH`, `REACT_BUNDLE_PATH` and `CHROMIUM_PATH` variables as the session-tree browser regression, plus `GRAFT_COMPILED_PATH` pointing to a locally transpiled `LineageGraft.js`. It checks real rc.5 production React and Chromium against a **synthetic** native row and Host, including lazy refresh, propagation, direct-parent navigation and collapse. The script rejects a nonmatching React asset hash. It is not the real WorkspaceBrowser, native DSH GUI, or installation test.

# Synthetic V4→V5 shape — not a migration

This isolated experiment uses the pinned public Session format declaration APIs at `b830ec950faba0a46dda564be3e2d854afed94f1`. It is not registered in the generated catalog, changes no Session format constant and cannot read or write a real Session. `edge.ts` is a synthetic header envelope and adjacent-stage shape, **not a complete V5 physical codec or production migration**. Its callers supply already-decoded events; its direct pass-through test demonstrates only that an opaque future `session/title.source.kind` and other synthetic fields can survive this stage unchanged. It does not establish that the actual V4 decoder accepts such an unknown nested source: it must not be silently admitted or interpreted. No user-message provenance is fabricated. Unknown inherited cuts, gaps and compact runs fail closed.

In the real pinned V4 catalog, `readHeader` classifies V5 as `unsupported`; `createRestore` throws for newer version. An initial test incorrectly expected `readHeader` to throw; `work/host-tests/title-v5-edge.log` retains that 2-pass/1-fail observation. The corrected synthetic test passed 3/3 under a reviewed sandbox denying network and specified installed-app/profile paths: test SHA-256 `e176b57454d5a0f899ab768092a4ce7d347c2fb0ed43f7392b5de9b726fe4ab9`, edge SHA-256 `a246914fb505666f23b313bf73c4f55fbd2e1bd0527dadd2faf28843e0bbab9c`, retained external log `work/host-tests/title-v5-edge-v3.log` SHA-256 `b353c20ae64d6c49fc8d504c12564ed60cf6175ea87863a7b1d69aa936bbcf60`. Individual hashes were recorded before and after the passing run; full transitive dependencies were not independently hashed. An earlier source-backed JSONL probe separately showed pinned V4 read/write refusal and unchanged temporary V5 bytes; no installed version was tested.

For a real integration, a complete V5 codec and source vocabulary, V4 restore validation, sequence/fork and seed-cut handling, preserving all supported and ignorable records, target semantic validation, generated catalog/constant evolution, durable generation verification and locking, crash/recovery and rollback strategy, writer coordination and user consent are all unresolved. Most critically the source event, Lead/child relationship, authorization and durable cross-session source cut remain UNKNOWN. Neither this stage nor a version bump establishes them; no genuine migration or title write should be enabled from this evidence.

To reproduce only the fixture: in a disposable exact pinned checkout with independently reviewed frozen dependencies, copy `edge.ts` to `synthetic-title-migration-wip/edge.ts` and the test to `packages/session/session-format/tests/title-v5-synthetic.spec.ts`; run the single Vitest file under a network-denying sandbox with personal paths excluded. No actual Session data is required.

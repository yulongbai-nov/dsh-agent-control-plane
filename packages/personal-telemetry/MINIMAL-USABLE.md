# R18 minimal usable 前置契约（CR-006，草案）

**状态：未实现、未验收；不是接入真实数据的授权。** 现有代码只用 `:memory:`，按本次使用约束仅处理合成数据（API 本身无法鉴别数据是否真实）；此页定义未来最小可用数据层接入前必须落实并验证的条件。当前禁止读取真实会话、写真实 profile/遥测库、导出或清除。默认范围仅授权工作区内、用户明确选定的会话的本地个人数值统计；该范围本身也需显式授权，产品 OTLP 完全分离。

1. **字段白名单和身份**：只采 rc.5 `tokenUsage` 四个 token 桶与 `sessionStats` 八个数值、必要版本/游标、已授权范围内的稳定去标识会话及源世代标识；各字段须有权威来源和有效类型，缺失记 `null/unknown` 而非 0。默认不存 prompt、回复、工具参数、标题、路径、模型、原始事件；`cwd` 等缺必要性时不存。稳定身份使用受保护密钥的 HMAC、域分离与密钥管理/轮换方案；hex 长度或无密钥 hash 不证明匿名，数值/哈希仍可能关联个人行为。原型已有合成白名单/形状校验，**无**身份生成、密钥管理或授权。
2. **unknown 与覆盖率**：按指标、授权范围及固定 cut 提供已知数、符合条件总数和缺失/未验证原因；不能证明总体/分母或范围完整时覆盖率为 `unknown`，不可用已知样本数充当总体或将 unknown 折成 0/100%。会话累计、fork 继承、continuable 子会话不得直接归因为单次调用或跨会话加总；token 最终样本可修正，序号递增不代表数值单调。原型只让缺失 unit 为 null、`freshness` 恒为 unknown，**无**覆盖率或调用归因。
3. **双水位与来源世代**：`observed/provisional` 表示进程观察到的逻辑切面，不证明落盘；`durable` 只能来自经验证的持久源连续前缀与真实尾部，标明来源世代、证据和 cut。启动/恢复核对世代、尾部及已提交 cursor；源缩短、库超前、换代、冷观察合成中断或证据缺失时停止推进可信水位并标 unknown，走经授权的恢复/重建。SQLite 与会话源非同一事务，不以数据库提交冒充跨库原子；如何获得可验证 durable 前缀及换代证据**待确认**，无证据不能标完整。原型 `asOfSeq` 仅为调用方合成观察值，**不证明**任一源水位或世代。
4. **重建、取消和防复活**：事实、cursor、来源世代及 tombstone 检查须在同一 SQLite 事务，按稳定身份/世代/序号幂等 upsert；重复重建无重复，冲突不覆盖；中断、崩溃回滚并保留 unknown。清除时同事务记录去标识 session 与源世代/seq 水位的 tombstone，回填、重复事件及重启均不可复活被清除数据；换代/身份变化和删除后新数据处理在明确策略与授权前拒绝/unknown。实际物理删除范围（主库、WAL/SHM、备份/导出）和墓碑保留期须事先说明，不能把逻辑删除宣称安全擦除。原型只有内存批次原子性、单源单会话序号幂等与同序冲突；**无**真实回填、durable 世代、tombstone 或清除。
5. **持久化与性能**：用户单独批准独立路径后，防符号链接/路径替换与竞态，安全创建目录 `0700`、数据库 `0600`，对 WAL/SHM 及备份验证等效访问控制、权限继承和崩溃恢复；锁定模式/迁移，拒绝未知 schema。`DatabaseSync` 不能阻塞 Host：worker 或有界批次让出事件循环，并验证取消与负载。原型 **不打开磁盘**，未实现/验证权限、WAL、备份、worker 或生产迁移。
6. **授权与披露**：收集/回填、本地私有报告、模型可见工具结果、Remote 跨机、export、purge 各是独立权限及披露通道；服务端逐次校验 caller、workspace、session、操作和目标范围；不能把 `sessionQuery` 可读或“不主动联网”当授权。导出/删除须用户明确确认具体范围及目的地/后果，拒绝未授权请求；默认保留期 365 天仅为 spec 目标，自动到期同样须 tombstone 防回填。原型 **无**真实授权、报表、Remote、导出、删除或保留策略。

**最小验收闸门（未来授权后）**：隔离合成及经单独批准的测试数据覆盖白名单/无正文、部分源与未知分母、异步落盘/断流/换代/源截短、重复/取消/崩溃恢复、清除后重建不复活、各通道越权拒绝、路径权限/WAL 及重启幂等；附可重复证据和已知限制。以上均不以此文档或现有内存测试冒充通过；durable 源证明、HMAC 密钥生命周期、墓碑策略及真实授权 UI 尚待确定。

# Synthetic continuation and cache accounting — nondeployable

This test-only zero-context patch targets public upstream `b830ec950faba0a46dda564be3e2d854afed94f1`; it does not install or alter the user's application. It uses the actual pinned SubagentRuntime, AgentLoop, JSONL persistence and token-meter turn fold with a scripted in-process mock adapter and task-owned temporary Sessions. A settled continuable child leaves the live agent registry, then resumes with the same Session ID, one persisted descriptor and the same mock provider/model strings; a separately created child has a different Session ID. The mock reports cache-read buckets 0 and 6 for the two continuations, and supplies an exact total but no cache bucket for a fresh child. The real fold preserves 0, 6 and **unknown**, respectively. These are deliberately programmed mock values, not evidence that a provider cached anything, a measured hit rate, or a reuse policy.

The first failed test accidentally included inter-turn events in the first turn slice; the next failed test expected a total despite omitting both exact total and cache buckets. The corrected test uses `turn/start` through `turn/end` only, and supplies a total when testing an unknown cache bucket. Those failures are retained as external `work/host-tests/cache-reuse-v1.log` and `cache-reuse-v2.log`; they are test assumptions, not established product defects.

The pinned descriptor snapshots explicit provider/model/effort names and relevant composition, but does not prove an immutable model binary, provider instance, preset revision, prefix identity, or provider-side cache lineage. The token-meter fold accepts reported counts only when its turn lifecycle and arithmetic are valid; missing or contradictory usage yields unknown. It cannot authenticate a real external provider's cache claims or prove two calls shared a cache. Archive/restore, actual preset revisions, real source/model, remote cache and performance remain untested. No production cache policy or hit-rate promise follows from this result.
